# esa-cli 1.0.14-beta.1

## Changes

- Accounts with a new compute plan can log in and deploy as soon as ESA reports the subscription as purchased. Accounts without a new subscription can continue using an active legacy edge routine service.
- Login and deployment report which account check failed. When the legacy service is still activating, the CLI prompts you to retry later.
- The CLI checks the beta channel for updates when running a beta release. JSONC configuration now preserves URLs that contain `//`.

## Compatibility

Node.js 18 or later is supported. Existing projects can keep their configuration and login commands. If you use a custom RAM policy, allow `esa:GetSubscriptionPlan` for the subscription check. Accounts using the legacy service also need `esa:GetErService`.
